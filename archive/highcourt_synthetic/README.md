# High Court version on synthetic data (archived)

This is the earlier build: a synthetic High Court with three benches, a pre-filing defect check on dummy PDF
filings, a two-stage multi-court planner (CP-SAT and MILP), logistic models for appearance and effectiveness,
a 60-day agent simulation, and the model-accuracy and optimisation-lab pages. It runs only on generated data,
so it is out of the product. The submission and the app use the organisers' real data only.

To run it, copy this folder's contents back over the repo root and run `python -m scripts.check_story`.
